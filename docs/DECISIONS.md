# Architecture Decisions

## ADR-001 — Spring Boot와 Python AI 서비스 분리

**상태:** 채택

Spring Boot는 배관·점검 이력, API, 시계열·위험도, 리포트를 담당합니다. Python FastAPI는 OpenCV, PyTorch, Ultralytics 기반 이미지 정렬과 추론을 담당합니다.

이 구조는 각 생태계가 제공하는 검증된 라이브러리를 그대로 활용하고 서비스 책임을 명확하게 합니다.

## ADR-002 — 배관별 Baseline 좌표계

**상태:** 채택

현재 이미지를 직전 회차가 아니라 배관별 Baseline 이미지에 정렬합니다. N회차 이후에도 결함을 동일 평면에서 비교하고 회차별 정렬 오차의 누적을 줄이기 위한 결정입니다.

Baseline 변경 시 새 기준 버전을 만들고 이전 결과와 혼합하지 않습니다.

## ADR-003 — 모델 미준비 기간의 Mock 모드

**상태:** 채택

실제 YOLO-seg 가중치가 준비되기 전에는 Mock 모드로 전체 파이프라인을 검증할 수 있습니다. 모든 응답과 화면에서 Mock 여부를 명확히 표시합니다.

## ADR-004 — 위험도 정책

**상태:** 검증 필요

면적뿐 아니라 열화 속도가 위험도에 충분히 반영되어야 합니다. 누유는 최소 Warning, 신규 누유는 Critical로 처리합니다. `gamma`, 정규화 상수, 등급 임계값은 실제 또는 대표 데이터로 검증한 뒤 확정합니다.
